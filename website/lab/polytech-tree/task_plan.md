# 互动知识树本地演示

## 获准发布

用户已明确授权commit、push、部署。采用已验证独立静态产物，不新增构建/应用镜像；官网新版本目录与Nginx片段备份后切换，保留旧不可变资源，不改画布/API/数据库。部署后核对公网首页/课件/媒体/许可及画布健康，再同步资讯基线与发布记录。

## 本轮展项视觉升级

沿用实时Three.js实例化场景和原始数据。浅色页面、深海蓝舞台、白色阅读面板；压缩页头/工具区，收敛节点尺寸与高光，名称增加深色轻底板及投影避让，选中/悬停区分，聚焦镜头平滑且减少动态时即时。首页继续轻封面入口，独立页面承载3D，不改画布或生产。检查、实现、构建和本地浏览器验收已完成；本轮实际截图供用户确认。55项检查通过，真机和生产检查仍在边界之外。无Git操作。

目标：官网案例入口与独立静态3D课件，不接画布、账号、数据库或生成接口。

阶段：参考代码/官网发布链已读；复用内核 → 轻量首页入口与独立页面 → 构建 → 桌面/手机/键盘/错误与WebGL降级验收 → 本地交付。不commit/push/建分支，不部署或修改线上配置。

## Direction contract

THESIS：让知识之间的关系可探索，真实科技之塔是主角，不制作科技公司式炫光装饰。
OWN-WORLD：继承官网冰蓝浅底、深蓝文字、克制圆角和透明分层；图形按领域着色，图例与数据对应。
STORY：访客在官网看到实际课件封面，点击后进入独立知识空间；筛时代/领域、聚焦节点、再漫游回到整体。
FIRST VIEWPORT：顶部返回官网和标题，主体为占满可用空间的科技塔；左侧紧凑筛选，右侧节点阅读区，底部操作与低权重版权链接。手机用上下堆叠，不能挡住场景。
FORM：用户已明确的既有世界扩展、代码实现；不进行重新设计或概念抽签。
FINISH：unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance

手机展示策略：像素比1、默认8个名称（最多24）、419个精选节点且不绘制逐字时代标签；桌面保留3862节点。该策略仅影响展示，不删改原数据。减少动态效果时禁用默认自转及连续漫游，改为逐时代查看。

已验证：独立构建、路由、首页无3D请求、渲染清理、许可与Chromium模拟桌面/手机及错误状态。真实手机硬件、Safari/Firefox和生产路由待用户确认本地效果后再安排。

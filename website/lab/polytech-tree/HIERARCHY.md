# 分层按需浏览：实现与性能核验

本轮只做本地版本，没有commit、push或部署；生产仍为v0.16.26平铺版本。本地预览：http://127.0.0.1:4411/lab/polytech-tree/ 。

## 展示机制

- 完整保留3862项知识、22个原分类、11个时代，以及全部prereqs/related、原文与署名；dataset、public许可/来源和LICENSE文件没有diff。12个顶层领域只是界面浏览目录，不加入科技事实数据，也不绘制虚构目录依赖。
- 领域每页30项实际知识，末页不足30则按实际展示；选中知识后呈现自身+最多30项前置/后续/相关技术（最多31）。所有页都能访问，超过30的关联不会丢失，60是防御性硬上限，不用截断数据保证预算。
- 替换分支时先释放旧实例、几何体、材质和标签，再按新可见集建立对象；未展开节点不分配实例矩阵、名字或边缓冲。仅为当前可见知识的原始prereqs构建关系线，不把related伪装为前置依赖。
- 面包屑记录领域/原页面/知识，支持返回、折叠关联、折叠全部和分页。全库搜索覆盖中文/英文/ID，可分页显示所有结果；选中结果或关系标签自动定位祖先页面，冲突筛选会清除。领域页按原始年份顺序分行；关联页为局部关系排布，不再将全部知识排成一根全塔。
- 缩远时名称预算由用户上限动态降至12/6，极远隐藏普通关系线；名称继续投影避让，选中和悬停优先。名称区域可轻触且拖动不误点。新页.24秒淡入，沿用原相机.85秒可打断过渡；减少动态时即时切换。

漫游适配了节点预算：绕行当前页，每12秒进入下一页，用户操作即停止；不再一次召回全塔。减少动态时改为手动“逐页漫游”，首次进入不会跳过第一页。原全塔螺旋漫游代码保留，但本入口不实例化它的排期。

## 修改范围

src/hierarchy.ts仅管理浏览索引/分页/定位；src/main.ts连接导航、搜索、可见页生命周期与LOD，复用现有PolyhedraField、buildEdges、DOM标签和CameraRig。controls.ts只增加空漫游计划支持，避免创建无用全塔排期。index.html/src/style.css添加面包屑、搜索和分页并沿用现有浅色/深海蓝/白面板体系；首屏不显示无效的返回按钮，小屏两列控件减少占高。

没有新增依赖，没有修改主画布、API、账号、数据库、官网资讯或生产发布配置；首页继续只加载轻封面。

## 实际对比

同机Chromium1243、ANGLE NVIDIA RTX2070/D3D11、1440×1000，本地Vite4413。每次独立浏览器上下文；同样拖动轨迹和滚轮输入，没有CPU降速。JS堆在主动GC后采样，WebGL缓冲由bufferData/deleteBuffer拦截统计；它们都不是整个浏览器内存或设备总显存。

- 首屏科技/目录实例：3862 → 12（旧版另外还有11个时代标签实例）。进入领域后实际实例30，最高关联页31。
- 首屏可操作时间：原版1340ms；新版多次采样457–716ms，最终扩展样本498ms。指导航开始到加载层隐藏，不能当作公网弱网或正式LCP/INP成绩，也不把单次原版和多次新版当作统计显著性结论。
- 首屏JS堆：9,380,764 → 7,342,216字节，约降22%；DOM计数23,738 → 698。
- 首屏WebGL缓冲：2,629,936 → 8,824字节；30项领域页面16,640字节。保留完整知识JS数据，所以不是把总内存降至几KB。
- 拖动FPS：143.6 → 144.0；缩放FPS：143.2 → 144.0。30节点领域页拖动/缩放也均约144FPS。该机已被144Hz刷新率限制，不宣称可感知FPS大增。首屏拖动脚本每帧约1.50ms → .47ms；缩放约.62ms → .27ms，反映主线程余量增加。

收尾压力补测曾发现只调用geometry.dispose时，40次切页缓冲从17,808涨至110,288字节。已补InstancedMesh.dispose，修复后30节点页面在切换40/80次后缓冲均为16,640字节，始终只有一个标签层。最终扩展样本对应GC后JS堆约8.57 → 8.89 → 9.09MB，并非零增长；短样本不能证明长期没有JS/浏览器缓存增长。

医疗器械制造 · 工程图纸原材料与零件号智能提取

Medtronic · 工程图纸原材料与零件号智能提取

Medtronic · 公开案例

依据公开资料整理，所列企业并非我们的客户；不构成收益承诺。

业务背景

Medtronic把工程图纸处理拆为OCR、RAG验证、结构化入库和专家复核，使AI不只“读图”，而是进入材料识别与供应链决策流程。

核心痛点

医疗器械产品工程图纸数量大且结构复杂，关键原材料和零件号识别依赖人工阅读与核对，既拖慢产品开发和供应链分析，也容易因为格式和图面差异产生遗漏。

实施方案

Medtronic全球运营与供应链分析团队、供应商管理团队和IBM共同构建定制方案：Azure Document Intelligence先做OCR和版面提取，Azure OpenAI支持的RAG结合工程上下文验证材料信息，关键属性写入数据库并通过简单搜索应用供业务人员检索。

AI完成图纸识别、信息抽取和候选结果生成；供应链与工程专家验证关键属性、处理低置信度例外，并对材料和设计决策负责。

技术组成

以下为编辑归纳，仅供方案讨论；不代表企业已公开确认的完整架构。

  • 复杂工程图纸与设计文档
  • Azure Document Intelligence OCR与版面解析
  • RAG检索工程上下文
  • Azure OpenAI生成并验证候选属性
  • 关键材料与零件号写入数据库
  • 搜索应用与专家异常复核

可复用经验

保留来源项目的经验归纳，适用条件仍需结合自身业务评估。

  • 复杂文档AI应拆分OCR、语义理解和人工复核
  • 不同字段应分别评测而不是只报总准确率
  • 抽取结果必须进入可查询的数据结构
  • 高风险工程信息需要置信度和例外处理机制

成果及局限

IBM案例披露，关键材料信息提取准确率最高达到90%，零件号提取准确率超过85%，显著减少人工核验并节省数小时处理工作；未公开总体成本节省口径。

  • 90%和85%分别对应材料信息与零件号提取。
  • 公开页面未给样本量、误差分布和外部评测。

## 体验与基线

源码仍是已验收 P1 的隔离目录 `H:/CodexStorage/shoushou-knowledge-p1/workspace`，没有错误地在尚未合并 P1 的正式仓库上开发。动工前核对 P1 的 1,069 个源码文件全部相符，并备份到 `H:/CodexStorage/shoushou-knowledge-p15/baseline-source`；P1 原报告、测试证据和正式工作区保留。

## 已实现

- 全局图谱：当前选中且经授权的个人/项目空间、真实有向 Wiki 关系、无连接节点、标签/文件夹筛选、按页加载节点和边、远端搜索定位、点击聚焦、双击打开文档、缩放/平移/拖拽/重置视角。
- 局部图谱：当前文档的一层正反向关系，按需扩展和高连接度分页；中心突出、方向颜色与箭头、间接关系变弱、悬停连线强调、切换中心与平滑镜头、返回上一焦点。已探索的邻居保留，避免每次切换清空空间感。
- d3-force 真实物理布局在独立 Worker 中计算；Canvas 2D 只负责按需绘制。节点排斥、链接弹簧、碰撞与中心力共同作用，拖拽附近节点响应，释放后继续降温并停止。
- 视图与文档切换、面板宽度和折叠过渡、节点进入与悬停强调使用统一 240ms 动效；prefers-reduced-motion 关闭镜头/界面动画并在 Worker 内直接求稳定布局。编辑草稿先保护，再切换视图。
- 默认首页随有无文档显示创建/导入或探索入口，图谱不叠加在正文编辑器上。图谱视图收起原文档关系栏，避免把当前打开文档的关系误当成当前图谱焦点，也避免高连接度文档在图谱外额外加载全部关系列表。

## 数据与权限

只新增 KnowledgeService.graph 只读投影与 `GET /api/knowledge/:spaceId/graph`。不新增数据库迁移，不改 Markdown、版本、链接结构，不写 CanvasConnection，不新增 MCP/Agent 工具。

全局节点和边分别使用稳定 UUID 游标分页，局部使用中心 ID 和邻接游标；默认 API 页为 20 条，图谱界面每批请求 100 条，局部额外包含中心节点。这是加载批次而非知识库总数限制；601 篇与 1,200 条边已完整读回，单节点 600 邻居可分六页全部展开。边的 source/target 均须在同一授权空间且未删除，只返回 resolved 关系，不用相似标题造边。

每一页查询复用现有活跃用户、个人所有权、项目未删除及成员权限检查，并使用既有事务读锁。无权限返回不可访问；撤权后的下一次查询清空图谱和焦点。回到页面时执行轻量权限复核，不清空已经探索的有效布局；内容新增/变化可手动刷新，没有新增实时协作或推送订阅。

API 返回标题、标签、目录、引用计数及边，不返回文档正文。布局缓存按用户/空间/模式/筛选隔离，仅保存 ID、坐标和镜头，不代替授权查询。异步请求切换空间、筛选或失效后不合并旧结果。

## 物理与性能

实际参数：forceCenter(0,0).strength(0.04)、forceManyBody(-170)、forceLink distance 95/strength 0.14、forceCollide 13、velocityDecay 0.4、alphaDecay 0.035、alphaMin 0.002。布局停止后没有永久 RAF 循环；空图直接停止 Worker 模拟，退出视图终止 Worker、观察器和事件监听。隐藏信号会暂停模拟与绘制，恢复时继续尚未降温的布局。拖拽保留其他节点的位置与速度，不随机重排；窗口失焦时释放未完成的拖拽，避免丢失鼠标抬起事件后保持非零 alphaTarget。合成失焦测试已验证无 mouseup 时仍会降温停止。

复用浏览器 IndexedDB 布局缓存；没有缓存时首次稳定后适配视野，用户手动操作后不再抢镜头。低缩放隐藏普通标签，密集区域简化标签；移出视野的节点不绘制。此版已将布局移出主线程，不引入 SVG 大量 DOM 或重型 WebGL 引擎。

以下均为本机隔离环境实际测量，不是生产性能保证，也不是端到端帧率：

- 等价绘制对照（合成位置，同等节点/边/标签）：2,000 点 SVG 平均更新 11.59ms、平均帧间 45.75ms；Canvas 2D 平均绘制 3.33ms、平均帧间 12.93ms。完整 4/40/600/2000 结果见 `artifacts/render-comparison.json`。
- 实际 4 篇知识：平均 Canvas 绘制 0.28ms。
- 实际 40 篇知识：平均绘制 0.57ms，观测最大 1.70ms；Worker 单步平均 0.18ms，观测最大 1.70ms。
- 实际 601 篇/1,200 条关系：平均绘制 1.15ms，观测最大 3.00ms；Worker 单步平均 1.81ms，观测最大 5.90ms。
- 601 篇文档经真实 KnowledgeService 创建并建立索引约 43.3 秒；全局各页查询耗时另见 `graph-query-timings.json`，不能把该导入耗时当检索延迟。没有通过限制文档总量达到性能目标。

实现参考：[D3 simulation](https://d3js.org/d3-force/simulation)、[D3 link force](https://d3js.org/d3-force/link)。依赖新增 d3-force 3.0.0 和开发类型包 3.0.10，连同三个传递包均已核对 ISC/MIT 许可与 LICENSE 哈希；没有升级其他既有包版本，见 `dependency-diff.json`。安装沿用基线的 legacy-peer-deps 方式，未在本轮升级或重构既有 Ant Design/pro-components 的 peer 组合。

## 实际测试

- 新图谱真实 PostgreSQL：7/7 Node 测试（含父测试）通过，覆盖四篇/孤立节点、一层邻接、40 篇标签/文件夹/游标、601 全分页、600 邻居、重名不造边、删除目标、跨用户、撤权/停用/删除项目和正式 HTTP 路由。
- 新图谱真实 Chromium：10 组通过，无页面脚本错误。验证实际拖动/邻居响应/释放降温/稳定后帧数不再增加、缓存复用、镜头与双击打开、局部展开/焦点返回、换空间与过滤、远端搜索、601 节点/1200 边、高度节点分页、离线草稿、深浅/手机/减少动画/默认视图和四篇孤立节点。
- 撤销项目成员后，真实界面下一次请求被拒绝且节点/焦点清空；合成 visibility 信号能停止帧数与 Worker 步数，恢复后继续冷却。原生后台可见性尚未验收，见下节；不将合成事件当成人工后台测试。
- 最终实际 HTTP：无登录、跨空间、非法节点/边游标及页大小被正确拒绝；图谱响应不含正文，查询前后文档内容/版本和正式画布结果一致。
- P1 回归：真实 PG 11 项、原浏览器 8+10 组通过，覆盖 CRUD、保存冲突、草稿恢复、保真/导入导出、目录和搜索。原业务 65 项、私有 MCP 13 工具/v2 重试与真实 Web/MCP CAS 竞争通过；旧写入口仍关闭，没有知识 MCP 工具。
- 原画布真实页面保存与可见文本节点回归通过，进入画布未请求知识编辑器或图谱。图片/视频/音频后端测试使用测试替身，没有调用收费供应商。
- API 构建、Web TypeScript 与 Vite 生产包构建通过。Worker 独立产物约 15.23kB，知识图谱懒加载；原应用既有的大块与混合动态导入提示保留，没有为消除提示修改生成业务。

完整证据在 `H:/CodexStorage/shoushou-knowledge-p15/artifacts/`：`graph-integration-first.log`、`graph-browser-validated.log`、`graph-browser-results.json`、`http-final-results.json`、`lifecycle-permission-results.json`、`p1-regression.log`、`p1-browser-*.log`、`workflow-regression.log`、`mcp-regression-final.log` 和构建日志。早期失败与诊断日志保留，不作为最终通过证据。

## 未验收与边界

- 真实后台标签页/最小化行为待人工：本环境自动化 Chromium 即使切页和最小化仍报告 visible，原生冻结后的采样也包含恢复工作，不能证明原生后台停止。合成 visibility 的暂停/恢复与关闭图谱的 Worker 终止已通过。请在体验窗口实际切到其他标签页或最小化后观察，再恢复验证。
- 真实 Windows 中文输入法仍沿用 P1 人工待验状态；自动组合事件不等于输入法验收。物理手机、Safari/Firefox、触控手势与长期运行未完成人工检查。
- 实测规模为 601 篇真实知识与 2,000 点合成渲染对照；更大规模没有生产保证，逐批加载不会限制数据库文档总数。密集标签可能局部重叠，可通过缩放、悬停、搜索和键盘选择定位。
- 没有新增知识节点入画布、AI 关系生成、Agent/MCP 知识工具、跨空间共享、向量库或实时协同。知识关系与生成执行边继续分离。

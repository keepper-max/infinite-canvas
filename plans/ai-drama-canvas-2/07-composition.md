# 第 7 部分：声音、字幕、时间线与 FFmpeg 成片

状态：`complete`（2026-09-10）

## 目的

把分镜视频素材、对白、音效和音乐组合为可预览、可下载的一集成片。

## 范围

- 配音、音效、背景音乐和字幕节点。
- 角色声音绑定与对白批量生成。
- 简化时间线：镜头顺序、裁切、时长、音轨、字幕轨和转场。
- 字幕生成、编辑、时间定位和样式模板。
- FFmpeg Worker：拼接、转码、混音、字幕、封面和最终导出。
- 合成任务进度、日志、取消、失败重试和临时文件清理。
- 成片作为不可变视频资产版本进入 OSS。

## 非目标

- 不做 Premiere 级多轨剪辑器。
- 不开放任意 FFmpeg 命令输入。
- 不在 Web 容器运行 FFmpeg。

## 重点风险

- ECS CPU、磁盘和带宽有限，初期 FFmpeg Worker 并发设为 1；实施前确认边界值。
- 所有输入必须先转存 OSS，避免 Provider URL 在合成过程中失效。
- 用户字幕内容和文件路径必须安全转义，禁止拼接任意 shell 参数。

## 验证

- 多个视频片段能按分镜顺序合并。
- 配音、音乐、音效音量正确，字幕时间对齐。
- 页面关闭和 Worker 重启后合成任务可恢复或安全重试。
- 失败不会留下长期临时文件或错误标记为成功。
- 输出能在线播放、下载并追溯到时间线版本。

## 完成条件

- 用户可以从第 6 部分生成的素材合成并下载完整一集。

## 回滚

- 合成输出是新资产版本，不修改输入素材；关闭合成执行器即可停止新任务。

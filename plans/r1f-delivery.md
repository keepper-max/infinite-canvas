# R1-F 本地整改交付

本轮实施三个发布阻塞的源码修复，只使用独立 PostgreSQL、Redis、MinIO 和明确标注的模型替身。未连接生产、未调用付费供应商、未提交或推送；本报告不构成生产发布授权。

## 实现

- 重试：客户端将逻辑操作 UUID 写入 IndexedDB，响应不明时先查询原回执，再以同 ID 重放。服务端使用操作者/操作 ID 唯一约束、请求哈希、原任务行锁、任务族事务锁和同事务回执，原子保存新任务、积分预占、事件和审计。任务 ID、retryOperationId、attemptCount 分开返回。相同 ID 不同参数返回409；有进行中的子任务时拒绝另建重试。
- 提交与账单：新任务从 not_started 开始；供应商调用前原子变更为 dispatching，收到回执后为 accepted/resolved。超时、断连、进程中断等无法核验的提交进入 unknown/dispatching 保护，禁止再次提交，账单进入 manual_review，不自动按免费处理。递归检查同一任务族的所有重试记录，任一层不明提交都会阻止从任何祖先任务另开重试，避免绕过。既有人民币积分、退款和结果交付逻辑保留。
- 客户端能力：新增服务端签发的一次性能力凭据，绑定操作者、项目、revision、服务端实际知识节点清单。客户端必须确认实际 ID/引用；全量保存必须完整保留知识节点或明确列出删除 ID。版本字符串和仅带最新 revision 均不能绕过。凭据消费与 CAS 保存同事务。旧只读客户端可浏览占位节点；未开放用户不获得知识引用。
- 灰度：独立 knowledge 授权默认关闭，按统一用户 ID 开放/撤销，管理员操作和原因同事务审计。KnowledgeService 全入口、知识节点追加/回执、模型来源解析、Worker 执行前校验、任务/事件读取及私有 MCP 适配均受服务端控制；项目成员权限仍须同时满足。邀请码不参与此授权。
- 写入口：REST全量保存/IndexedDB导入使用能力凭据；Agent 显式节点操作仍经网页保存；MCP v2 服务端追加必须保留已有知识引用；恢复只允许服务端选择的历史且仍检查权限/灰度。旧直库工具继续拒绝。发现旧 Mock Worker 非 Vibe 分支仍直写节点，因此将其候选源码改为明确退出，禁止连接队列或数据库；未替换任何已安装或线上 bundle。

## 兼容与边界

- 旧无参数 retry 调用映射为操作者范围内 `legacy:<原任务ID>`，重复请求复用第一次结果；要发起第二个独立重试须升级为显式新 UUID。原始请求和历史任务不改写。
- 旧任务新增状态为 legacy；已尝试且没有可核验供应商回执/账单的任务拒绝新付费重试，交管理员核查。不会把历史失败推断为未提交，也不会删除任务或历史账单。
- 含知识节点的旧页面保存返回 CANVAS_CLIENT_UPGRADE_REQUIRED / CANVAS_KNOWLEDGE_OMISSION。新版未读取该 revision 的基线时保留草稿并要求重读，不在后台自动合并覆盖。无知识节点的现有画布仍可使用旧保存协议。
- 非灰度用户在含知识节点的画布上只读，知识引用显示占位；这是发布保护的明确兼容边界。用户升级/获得授权后重读完整状态再保存，禁止将占位内容写回。
- 同一项目任务列表/事件页包含知识来源任务时，未授权用户收到403，而非收到部分知识事件。生成结果仍按原项目素材权限管理；撤权不删除已经合法生成的创作资产。
- `manual_review` 不会自行解除提交保护。恢复必须有供应商原执行/账单证据和单独受控处理；本轮没有新增自动重放或自动退款通道。

## 验证与证据

完整运行数据见 `H:/CodexStorage/shoushou-r1f`，最终机器报告及文件清单见本报告相邻的 r1f-validation 和 r1f-changes 文档。所有失败过程保留，最终结果以明确标注的最后一次运行为准；测试数量包含 node:test 的父项。

已实测真实 PostgreSQL/HTTP 并发重试、回执参数冲突、故障注入回滚、并发 CNY 积分账本唯一性、旧/新客户端竞争、灰度及项目隔离、源码保真、真实 Redis Worker 和本地 HTTP 模型链路。浏览器使用实际前端服务模块，模拟服务端成功后丢失 POST 响应；刷新后只查询原回执，未再 POST。真实 Worker 重启后，恢复队列中的不明提交不再次调用模型。

本地 API/Web 生产 target、私有 MCP 候选及类型检查均单独记录。既有 Agent 未修改；此前 R1 的127项测试保留为历史证据，本轮 Windows 直接 npm test 因该目录未装 tsx 无法执行，不把它算作本轮通过项。

未验收：生产 PG/S3 配置、线上旧写者和插件缓存、生产备份、真实供应商/RMB结算、真实 Windows 中文输入法与物理移动设备。上传中持画布锁风险仍存在，未擅自重构上传架构。

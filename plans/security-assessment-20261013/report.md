# 守守画布安全初检报告

## 结论
这轮有限检查没有成功绕过未登录鉴权，没有证明服务器或账号可被接管。发现两个优先处理的代码级攻击面和一个登录防护缺口。不能用本报告承诺系统安全，也不能将本地复现视为线上漏洞利用成功。

## 优先修复

### P1：远程参考素材取址缺少内网限制（SSRF 风险）
- 根因：job-contract.ts 仅限制 HTTP(S)；未绑定云资产版本的 URL 保留原值，RunningHubProvider.uploadReference 直接 fetch。
- 验证：契约接受回环地址，实际上传器进入取址调用。本地替换 fetch 后断言命中，未连接任何真实内网服务。
- 影响：具备任务权限且可走相关模型通道的用户可能驱使工作进程读取内网 HTTP 内容；读取内容随后可能被上传到供应商。实际可用模型、计费门槛和出网隔离未核验。
- 修复方向：优先仅使用已授权的云资产版本；确需外链时，统一做目标/DNS 地址检查、重定向逐跳检查及网络层内网限制，不要仅匹配 URL 字符串。
- 证据：server/api/src/job-contract.ts、job-service.ts resolveAssetReferences、runninghub-provider.ts:282。

### P1：主动 SVG 内容可能以同域文档执行（潜在存储型 XSS）
- 根因：上传允许 image/*，包含 SVG；完成上传仅核对声明属性与对象元数据；媒体接口按原 MIME 返回，接口自身没有隔离 CSP 或强制附件头。
- 验证：本地契约接受 SVG，假存储媒体响应为 image/svg+xml，无 Content-Disposition 和 CSP。没有上传攻击文件，没有浏览器脚本执行或受害者测试。
- 影响：若包含主动内容的素材可被另一成员或管理员作为同域文档打开，可能使用其登录态发起请求。普通 img 显示 SVG 不等于必然执行脚本；访问权限、打开方式与生产实际响应头决定可利用性。
- 修复方向：上传 SVG 清洗/栅格化，或放到无账号 Cookie 的独立媒体域；同域主动格式采用隔离 CSP / 下载附件。同时复核旧素材和缩略图，不能只修改前端选择器。
- 证据：server/api/src/asset-contract.ts:77、asset-service.ts completeUpload、app.ts:2208、ops/edge/media-cache-locations.conf。

### P2：两个密码登录入口没有应用层失败限流
- 根因：/api/auth/login 与 /api/auth/login/password 直接查询账号和验证密码，未见账户/IP 失败计数或延迟控制。
- 验证：本地假仓库各 12 次失败均进入处理并返回 401，无 429；没有在线爆破。生产 WAF/外层限流未核查。
- 影响：增加撞库和弱密码猜测风险，已知账户的 Argon2 校验还会消耗资源。
- 修复方向：两个入口共用 Redis 原子账户+可信来源 IP 限流，避免只保护其中一个；控制锁定策略，防止攻击者恶意锁他人账号。新增阈值先由用户确认。
- 配套风险：clientIp 优先信任客户端可携带的代理头；必须由可信入口清洗并覆盖，不能把该值直接视为真实来源。
- 证据：server/api/src/app.ts:276、394、2682。

## 用户授权后的加固结果

上文是修复前初检记录。用户随后授权实施，并明确了阈值；当前工作区已包含以下改动，未提交或上线。

- `remote-media.ts` 统一检查 HTTP(S) 媒体连接；使用 ipaddr.js 判断保留/私网 IPv4、IPv6 和映射地址，undici 连接器校验实际 DNS 回答，所有跳转新连接再次检查。RunningHub 参考素材上传及生成结果转存接入；授权云资产继续使用对象存储读取。策略拒绝是明确失败，不无限重试。
- `media-security.ts` 定义无脚本、无同源权限的文档 sandbox CSP，保留图片/视频加载和下载；API 媒体响应及 ECS 边缘缓存模板均施加。签名对象链接默认附件，旧文件不变。
- `auth-rate-limit.ts` 实现 Redis 原子滑动窗口和并发占位。密码失败每账号 5 次/5 分钟；验证码发送与错误校验各自每账号 5 次/5 分钟；密码和验证码错误共用每 IP 10 次/15 分钟，触发后冷却 3 小时。成功和非凭据业务错误释放占位，验证码发送保留既有间隔与日额度。Redis 不可用返回 503。
- 新旧登录、注册验证码、找回密码及发送入口由 API middleware 统一接入。来源 IP 先检查 socket 对端，再从可信私网代理链右侧识别最近公网地址，忽略 CF/X-Real-IP。上线前必须核验代理链，API 不得公网直连。
- 改动位置：server/api 的 package/lock、app/index/job-service/object-storage/runninghub-provider 及上述三个新模块；四个新测试文件；ops 边缘媒体配置和发布手册；CHANGELOG、两种语言的 todo/pending-test；本目录记录与无害探针。

- 用户已要求按建议实施；不包含提交、推送或部署。
- 远程素材：复用成熟 IP 解析与 HTTP 连接器，在实际连接处校验 DNS/地址，防止重绑定与重定向绕过；自有云资产走现有对象存储，不一刀切屏蔽正常素材。

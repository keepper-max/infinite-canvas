## 已确认根因

- **导入/返回卡住**：普通单次 Markdown 导入实际可以成功，没有证据支持“文件选择器遮罩”推断。真实浏览器复现的是读取文档期间返回无 doc 的知识首页：`use-document.ts` 在空 ID 分支提前返回，未清零 loading；旧请求的 finally 又因 generation 已改变而不能清理。另有操作 busy 与空间切换共享、旧请求 finally 无法清理当前状态的风险。现按文档/空间隔离状态，切换前保护草稿；停止等待仍保留原 operationId，并先查询回执。
- **空白/灰按钮/接口不存在**：初始化把空间与项目请求绑在一起，项目失败也会阻断个人空间；未就绪仍能挂载图谱。隔离浏览器真实发出 `GET /api/knowledge//graph?pageSize=100`，正式 Hono 路由实际返回 **404 / NOT_FOUND / 接口不存在**。这和资源级 `KNOWLEDGE_NOT_FOUND` 不同。现在独立初始化、显式失败/重试、有效空间守卫及请求取消，不发送空空间路径。响应式布局原来进入窄屏后永久关闭桌面侧栏；现在桌面偏好与移动浮层独立，按账号保存。
- **关联入口缺失**：图谱原来只读取 Wiki Links，没有可达的写入交互。现补全全局/局部图谱节点右键及悬停操作、搜索消歧、方向与原文预览、建立、来源定位、精确移除。

原始请求/响应、发起栈和 URL 空间上下文见实验 `artifacts/before-errors.json`；合成用户身份位于实验 private fixture，不在报告中展示会话。没有取得用户原始录屏的网络日志，因此不把隔离复现声称为那次线上请求的确定证据。

## 实现边界

- 新增只读 `GET /api/knowledge/:spaceId/documents/:id/link-preview?targetId=…&action=add|remove`；现有 actions 增加 `document.linkAdd`、`document.linkRemove`，payload 为 `id / expectedRevision / targetId`，外层沿用 operationId。
- 复用 KnowledgeService 原事务、权限、CAS、历史、审计、幂等回执；未新增表、索引、迁移或运行依赖。只写真实 Markdown 引用，关系索引由正文重建；同名选择使用已有 bound_target_id 机制，不伪造独立知识边。
- 追加保留源文完整前缀和换行格式；未知内容、附件、Frontmatter、Callout 与代码不做重新序列化。未闭合代码等无法安全追加时拒绝并提示编辑器处理。
- 精确移除通过 Markdown AST 的真实来源偏移；多个引用、实体/转义导致偏移无法确认时禁止自动删除，打开源码定位。移除前序引用时保留后续已消歧目标身份。
- CAS 确定拒绝后清除“待重试操作”，保留冲突草稿；刷新仍显示冲突。未收到回执则继续保留原操作，不生成新 ID 盲目重试。
- 图谱引擎仅增加节点上下文菜单回调，保留 D3/Worker/Canvas 2D 主视觉、物理参数、布局缓存和执行边边界。编辑器/图谱局部错误边界保留页面返回入口。

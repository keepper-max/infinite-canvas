# R1 真实模型验收与预算提案（未执行）

本轮真实供应商调用数为零、费用为零。本文件列出需要用户单独批准的测试；预算是申请上限，不是供应商报价或已发生费用。

## 前置条件

- 在独立预发布账号/项目和数据库执行，仅用合成知识，不复制生产作品。供应商密钥只从既有服务端密钥存储引用；不得复制至浏览器、报告或测试源码。
- 从已批准的模型目录核对具体 modelId、provider、实时输入/输出价格、最大上下文、人民币计价/折算来源和账单查询能力。当前未获生产只读核查，不能预填生产模型 ID 或声称当前价格已核实。
- 先处理失败重试接口的幂等阻塞。实测对同一失败任务两次 retry 会产生两个新任务候选，现阶段不能开启故障重试的付费验收。
- 确认供应商是否提供可靠请求幂等键、按请求查询账单和已接受请求状态。若不提供，提交回执不明必须停在待核查，不能发第二个请求来“证明恢复”。

## 推荐第一批：文本链路，总上限 ¥10

最多 4 次正常付费提交，每次审批上限 ¥2，另留 ¥2 故障恢复预算。单请求只有在实时报价和服务端已支持的输出上限能落入预算时才执行；无可核验上限、价格不明或账单未终结时停止，不临时放大预算。供应商侧预算/余额限制需确认有效，人工审批上限本身不是程序硬限额。

1. Latest 第一次：人物文档 r1 + 随机校验标记，真实模型返回标记及引用证据。保存实际 outbound 资料哈希、任务 ID、供应商 request ID、来源版本和账单 ID。
2. Latest 更新：原文改为 r2，显式再次执行。验证新任务收到 r2，旧任务仍指向 r1；单改原文不会自动增加供应商请求。
3. Pinned + 多文档：Pinned 人物 r1、Latest 世界观 r2、第三份知识一起输入。要求返回三份合成证据标记；检查冻结全文/hash/revision/引用范围与实际请求逐项相符。
4. 丢失网页回执：只在服务端已持久化任务后阻断浏览器响应，再用原任务/原请求标识查询。供应商提交数应为1、回执及人民币账单只归属该次任务，不能换 operationId 新建提交。

无付费提交的验收：超预算上下文、空文档、撤权、停用和删除项目均应在调用供应商前拒绝，数据库无新增应收/实扣、无新增队列任务。撤权后的新调用与新 retry 都必须拒绝；已被供应商接受的请求不能承诺追溯撤回。

失败重试的追加验收使用预留 ¥2：先在供应商请求发出前注入本地故障，再通过批准后的稳定 retryOperationId 重试；回放同一重试请求和双客户端并发都只能产生同一个新任务与一份结算。对“供应商已经接受但响应丢失”的场景，先查询供应商原请求；没有可查询状态或不能保证不重复收费时标记未通过，不做盲重试。

## 可选第二批：图片/视频/音频，总上限 ¥30，另行批准

- 图片：1 次最小可用生成，单项上限 ¥5。
- 视频：1 次供应商当前支持的最短/最低合格规格，单项上限 ¥20。
- 音频：1 次短合成输入，单项上限 ¥5。

规格、实时价格或合法可用模型不满足单项预算时不调用。复用生成结果验证素材入库、下载/Range、权限、任务与 CNY 账单，不为了多轮回归重复付费生成；不进行真实支付宝充值、银行卡交易或退款。

## 证据与通过标准

- 本地 outbound 记录仅输出资料哈希/版本/范围、受控随机标记和 request ID；不记密钥或真实个人知识。供应商日志如可用，核对接受的请求；模型回显标记只能证明其处理了相应合成资料，不能单独证明全部正文逐字接收。
- 前置拒绝不得有供应商请求/扣费；同一逻辑请求、同一 retryOperationId 不得重复提交/扣费；显式新的生成属于另一笔操作，不能把它当幂等重放。
- 结算必须等待 billed/currency/amount_final 等实际回执与现有人民币账本一致，预留、释放、实扣各有证据。不把 HTTP 200、任务完成或替身金额0当真实结算成功。
- 每项记录实际 modelId/价格快照、任务/供应商/账单 ID、请求次数、CNY 金额与未通过原因。任何一次费用不明、来源错误、越权或重复任务均立即停止后续付费测试。

建议先批准“只读核查”，待重试修复通过后再单独批准第一批 ¥10；第二批 ¥30 不包含在第一批授权内。

# R2 发布与安全回退

## 候选与保护

使用正式仓库增量，不覆盖并行官网草稿。API、原生成Worker与新增AgentWorker使用同一批源码和锁定依赖；Web保留原插件和独立站挂载。所有迁移由已冻结LF字节构成，历史0049以前哈希逐项对照生产记录。

生产最新备份：/opt/infinite-canvas-backups/r2-20261025T043512Z。95表一致性导出后恢复到独立PG，对全表行数/行哈希核对；1663对象、4044492833字节在独立MinIO恢复后核对内容SHA256、长度与元数据。首次0050–0054迁移前另保留84表恢复副本和迁移预演记录。旧镜像及配置已保留。发布前复核最新状态、队列及制品清单，增量迁移先在恢复副本运行。不能启动新版自动迁移进程来替代此门槛。

## 切换顺序

1. 核验候选SHA256、历史迁移、备份验证、现有服务健康、原Worker和在途任务。暂停原任务队列，只在活动任务排空时切换，保留原暂停状态。
2. 独立迁移程序执行0050–0054，策略默认关闭，禁止修改历史迁移哈希。旧画布、知识文档、用户、积分和账本逐项保持。
3. 发布新版原生成Worker与API，仍关闭Agent付费执行；发布独立AgentWorker，验证Redis健康检查、并发与恢复。保留原导入服务及其配额，不把Docker权限授予API。
4. 在管理员策略中仅启动只读模型验证；使用已授权专用验收账号、项目及总费用上限¥1，仅Qwen3.5 Flash，不重试不明请求、不调用媒体模型。
5. 真实工具调用与现有账单结算通过后开放Qwen为默认模型，服务端native_agent默认覆盖全部活跃账号及后续注册，保留显式单账号拒绝。原画布KNOWLEDGE_GENERATION_ENABLED仍为false，仅Agent经批准的知识推理开启。
6. 发布Web，检查普通用户/管理员、正常知识和画布、模型选择/预算、一次审批的真实4节点3边及刷新持久化。保留实际Run/Step/Job/账单与来源证据，不把本地替身计入真实模型验收。

## 失败处理

迁移哈希漂移、无法恢复的备份、旧Worker未排空、权限失效或账单不明时停止对应步骤。不得重发未知付费请求。模型验证未通过则不开放该模型；故障时停止新增Run和写工具，保留读取、历史与普通业务。

管理员通过PATCH /api/native-agent/admin/policy提交enabled=false（expectedVersion、稳定operationId及reason必填）。即使供应商不可用也允许紧急关闭。停止AgentWorker后保留API历史查询和原生成Worker的新安全代码，不将旧Worker接回可能包含新模型任务的队列。恢复Web可用保留的旧制品，但服务端客户端能力保护继续开启；不删除Agent表、知识节点、快照、账单或回执，不降低revision，不重新打开旧直库MCP。

## 管理与监控

后台入口/admin/ai/agent-models。配置CAS、操作ID和管理员审计保存在既有platform_settings/admin_audit_logs；实际核验记录绑定模型适配定义与服务器凭据指纹，凭据不返回前端。默认每Run上限¥1，可管理员审计调整；16轮、32工具、64k Token、15分钟、每用户1个未结束Run、全局2并发、12k/2k上下文输出及60s/30s超时不扩大，失败即停。已有Run保留实际模型及准入配置，每轮记录执行时配置版本，禁用不自动切模型。

关注API错误、Worker健康/队列、manual_review与预留、模型分组Token/人民币费用/暂停失败占比、CAS冲突、权限拒绝和余额异常。后台“实际核验”会产生现有积分费用并要求确认，普通刷新不调用供应商。单账号撤销复用POST /api/native-agent/admin/grants/:userId，enabled/reason；项目/知识权限仍独立校验。

## 未验收边界

真实Windows输入法、物理手机与长期运行需人工验收；不扩大原媒体生成权限、不开发P3。已有旧素材缺失及不兼容历史快照沿用既有保护。模型全上下文容量仅显示目录声明，不宣称实测。生产真实付费结果以最终交付记录为准。

实际部署和真实费用验收已完成，生产全局策略v7开启；默认Qwen，77个有效账号默认开放。补丁及明确授权的原Run分段续跑、累计¥0.12和未验收边界详见ops/releases/v0.16.37.md。

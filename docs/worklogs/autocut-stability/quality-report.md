# AutoCut 真实素材质量验证记录

## 当前状态

四类要求的真人/实拍素材均未完成验收。检查范围为既有 AutoCut 测试目录、正式仓库相关测试资源和已知上轮样片；没有将其他项目/客户的视频默认视为已授权，也没有自行向模型上传。

已找到的 `speech-video.mp4`、`speech.wav`、`video.mp4` 是自制测试素材；`real-ai-output.mp4`、`rerender-output.mp4` 及本轮 `first-cut-output.mp4` 是其衍生结果。它们只能用于工程/转写/渲染回归。

## 四类缺失素材与当前结论

- **真人中文口播**：缺有明确使用权、允许模型分析的真人原视频及对应人工转写。内容识别准确率、口音/口水词、自然断句及唇音同步未测；TTS 文字保留结果不能替代此项。
- **长访谈**：缺完整原片、多人/单人标识和应保留观点/上下文的参考标注。精彩段落、跨窗口上下文、观点完整性、重复率、长期时延/费用与失败恢复未测。
- **实拍旅行或探店**：缺多镜头实拍原片或素材组，及地点/事件顺序、希望保留的镜头和目标风格。视觉识别、动态抽帧充分性、叙事排序、精彩镜头选择与重复率未测。
- **多素材商品宣传**：缺同一商品的授权视频、图片、声音/音乐及卖点、禁用镜头和目标成片要求。素材间一致性、卖点覆盖、多模态选段、原声与配乐、时长及最终质量未测。

上述类别的质量、全流程耗时、模型费用、CPU/内存/磁盘值均记为**未测**，不是 0，也不是通过。后续接收素材时需同时说明使用权及允许提交模型分析的范围；不要求把敏感素材上传聊天。

## 本轮实际完成的有限样片测试

输入是已有授权自制 TTS/图形 MP4，15.280 秒。使用实测 ASR/视觉缓存，新模型仅返回四段源区间；没有手工修正模型输出。

- **识别、完整性与边界**：4 条程序字幕，成片真实再转写与源转写文字一致；不能外推真人识别准确率或语义选镜质量。首次严格契约、源/成片坐标、重排、跨片段求交与半开边界已自动化回归。
- **镜头与重复**：四段区间按素材版本计算唯一覆盖率，源时间重叠率为 0；彩条/图形不具备实拍“精彩度”评价意义。非重叠不代表不存在视觉内容重复。
- **字幕和原声同步**：音视频起点均 0，音轨 7.315 秒、容器/画面 7.320 秒，烧录字幕一帧人工查看未乱码/裁边；没有真人嘴部，未做感知唇音同步验收。
- **时长与要求**：任务目标 30 秒，实际工程 7.315 秒，约为目标 24.38%；素材总长本就不足 30 秒且任务要求剔停顿，程序明确提示短于目标，没有循环/补造内容。该例验证“不凑时长”的降级语义，不能算“精确达到目标时长”。
- **耗时、费用与资源**：缓存路径尝试约 33.694 秒、新模型 ¥0.00055114；冷完整素材理解未重跑，且同机有 ASR 基准负载。ASR 独立资源数据见交付报告；首次剪辑全流程的 CPU/内存/临时盘峰值未单独采样，不能用 ASR 值或旧版渲染值代填。

## 后续评价口径

- **内容与语义**：用人工转写/观点标注对照 ASR、候选依据、选中范围；分别记录错字、漏观点、断句和上下文缺失，不用模型自评分替代。
- **选镜与重复**：人工标注应选/不应选镜头，核查地点/事件/商品；同时记录源区间重叠率与视觉内容重复，解释必要的重复品牌镜头。
- **字幕与同步**：核对字幕边界和文本，并对有真人发声的片段逐段感知检查；文件时长及起点相同仅是客观检查的一部分。
- **长度、时间与费用**：记录用户目标、实际长度、降级原因、冷/热全流程与各阶段时间、实际账单/调用次数；缓存复用单独标记。
- **资源与稳定性**：记录模型/FFmpeg/Node 的进程或容器资源、临时盘采样和正常清理；观察取消/中断/排队/异常输入。先确定样本和基线，再按结果决定是否需要开源组件。

## 开源增强结论

没有新增第三方剪辑组件。当前缺少对应实拍对照，不能证明 AutoClip 索引/分窗、中文语义边界、FireRed 视觉分组或动态抽帧能改善此系统；不以 README 或一段图形样片决定引入。

# AutoCut P1 技术设计与 V1 审计

本轮仅本地功能开发，不部署生产、不做客户端/实拍/付费验收。P1 默认关闭，未经实际客户端验证的格式标为实验性。

## 已读代码事实

V1 只有一条连续视频轨，允许额外音轨；顶层字幕数组保存成片坐标。片段 effects 仅音量/静音，fade 实为片段头尾淡黑。预览历史MP4，数字编辑只保留undo。服务端save校验不可变素材权限及分析数据后，CAS比较current_revision_id，插入新revision；restore仍创建新revision。Worker复用BullMQ并发1、PG任务锁、费用幂等及ASR缓存。

## 最小兼容扩展

- V1 Schema、选段协议v3、渲染函数保留。schema_version=2单独校验及渲染；AUTOCUT_P1_ENABLED默认false。旧工程打开精修时内存升级，明确保存才产生v2版本；恢复V1版本不删除历史。
- v2主轨连续或使用声明的转场重叠；叠加轨、原声轨、音乐轨可在不同时间重叠。视频不再隐式重复混原声，升级时抽成linked_clip_id关联的原声片段。
- 效果共享纯TS数据/插值解释器，浏览器和Worker共用。时间为毫秒、半开区间；关键帧使用成片绝对坐标。转场区间精确等于相邻主轨重叠，混音同时按区间淡入/淡出，总时长=sum(片段时长)-sum(重叠)。
- Transform/Animation/Filter/Audio/Transition仅接受受限参数，不接受命令、HTML或脚本。静态模糊/锐化不假装支持动态关键帧；字幕暂不支持旋转或滤镜，明确拒绝。
- 新功能仍走原权限、不可变资产版本、revision、任务、队列、预算和账本。P1保存不运行模型，源素材轻量预览不运行FFmpeg；渲染/工程导出用Worker。

## 已确认资源边界

16轨、200片段、1000效果、每效果128关键帧。ZIP≤5GiB，沿用并发1、30分钟、20GiB临时盘及15分钟下载签名；超限拒绝，无自动付费重试。输出仍720p/500MiB，FFmpeg两线程。

## 导出依赖审查范围

pyJianYingDraft 0.3.1 commit 1e228479dda361e312e85f6037002346cf6dca9a，Apache-2.0；上游声称部分新版10.8能力，但本机11.5未经验证。pyCapCut 0.0.4 commit ec61408d9f039c4045f946370bb35746b89b2479，本次未找到许可证，未安装/复制/启用该依赖；仅保留受禁用门控的分支，不构成已完成适配。OpenTimelineIO commit 94e1ad6c9b3c550b7ef06d999166c99b4be3025a，Apache-2.0并附上游声明；OTIO表示能力与FCP XML适配能力分别报告。第三方仓库只克隆到H盘隔离目录，不污染现有ASR虚拟环境。

## 预览与渲染边界

源素材使用已鉴权同源媒体接口。播放头驱动源时间=(成片时间-片段起点)*speed+source_in，图层按轨道层级合成，原声及音乐各自同步。默认空间坐标相对720p画布，字幕样式保留。滤镜/字体及解码色彩在浏览器与FFmpeg可能存在差异，界面明确显示近似预览提示；最终MP4是确定性导出结果，不把实时画面当作验收通过。

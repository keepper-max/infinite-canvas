# Agent只读任务修复交付

本地实现与隔离验证已完成；用户已批准提交、推送和最小生产热修，实际发布结果见ops/releases/v0.16.52-agent-readonly.md。

## 行为修复

- 新增read意图，读取、统计与业务修改分开；服务端将当前用户明确只读且全局禁止写入的指令作为权限上界，即使模型误报action也不提升写入能力。
- 读取结束正常完成，不请求写计划或审批，不额外花一轮模型费用。
- 历史回执加载时只收窄有效能力，不修改模型原文、快照hash或账单；恢复回执也必须服从当前只读工具范围。
- 已有完整答案、没有待执行调用或计划/审批且仅因无写计划暂停的只读任务，用户显式恢复后可直接收尾，零新增模型调用。不完整、未知提交、真正写入无计划或已有审批都不走该捷径。
- 真正的“先读再写”和标题含“只读”的写入请求保持原审批流程；不直接把所有空工具调用当作成功。

用户明确授权 commit、push、部署，取代前一阶段仅本地开发的限制。本次仅纳入 AutoCut 相关源码和依赖；未纳入 DS 连接实验、官网、archify 或本机私有验收文件。

现网 AutoCut V1 源码纳管；新增默认关闭的 P1 精修、v2 Timeline/Effects、低清预览与独立 SDK 工程导出。公开部署仍将导出标为实验功能，CapCut 缺许可保持禁用。原模型 Worker 与独立 Agent Worker 镜像保留，API 继承现网 v0.16.52，不能用旧整包覆盖 Agent 热修。

候选从暂存树单独导出构建，API/Web 构建通过；已配置生产凭据精确扫描零命中。继承现网 CPU Worker 的单独 Linux 导出 venv 不修改 ASR 环境。既有插件目录及独立 3D/项目目录挂载保留。

## 备份与切换条件

生产数据库一致性备份位于 `/opt/infinite-canvas-backups/autocut-p1-20261027T090526Z`，100 张表已实际恢复并逐表核对行数与内容摘要，全部一致。完整生效 Compose 和全部组件不可变镜像引用已私有保存；对象不覆盖、不删除。本次不增加数据库迁移。

切换前检查无在途 AutoCut 任务，暂停新任务及队列，短暂保护监控免于维护窗口误报；只重建 API、Web、AutoCut Worker。候选 Linux 构建、核心媒体/SDK 与迁移无漂移检查通过后才启用 P1。保持并发 1、2CPU/10GiB/20GiB 与既有费用/权限保护。

## 验证与回滚

通过管理员与已授权普通账号执行不付费的保存、渲染、下载和工程导出冒烟；不调整身份/余额，不把合成素材或程序校验当作真实质量/目标客户端验收。本次不要求付费 AI 效果或剪映客户端验收。

回滚先停收并暂停剪辑队列，保留 v2 项目/资产/任务/账单。若已经产生 v2 数据，应保留支持 v2 读取的 P1 API 并关闭精修入口，不把 v2 交给旧 Worker；V1 可以继续工作。确认没有 v2 活跃任务后再恢复旧 Worker；仅在没有用户 v2 工程依赖时回到整套旧 API/Web。禁止 down migration 或恢复旧库覆盖生产。

实际镜像、提交、线上冒烟、资源与停收恢复结果在发布收尾追加。

构建曾因NumPy 2.5.4不支持Linux Python3.11而停止，未切生产；导出锁按Python版本区分，3.11使用已验证的2.4.6，3.12及以上保留2.5.4。

隔离源码回归发现历史迁移已有CRLF/LF字节差异。现网51份迁移与Git SQL语义相同，发布制品继承原镜像的全部迁移原字节；本机旧QA库与当前Git换行不同，最终迁移与PG回归转到生产备份的独立Linux副本执行。严格迁移校验不放宽，不改生产迁移记录，不重新执行旧SQL。

SDK第二次下载遭遇Git网络失败后，改为从已审查固定commit生成wheel，并下载CPython3.11官方平台轮子，逐文件记录SHA256后离线安装；不重复从不明分支拉取，不修改原ASR依赖。
